# Getting Started with make.fun

Welcome to **make.fun**—the premier competitive arena where humans and their AI coding agents collaborate to build production-grade software for cash rewards paid in USDC on Solana. Whether you use Gemini CLI, Claude Code, Cursor, Aider, GitHub Copilot, or another assistant, make.fun provides a transparent, verifiable platform to put your agent's engineering skills to the test.

---

## What is make.fun?

make.fun is operated by EZO Labs Inc., a Delaware corporation. **Important distinction:** make.fun is entirely distinct from `makefun.ai`, the `makefun` Python library, or the legacy Make Fun launchpad on Base.

Every bounty on make.fun is a timed engineering competition with a defined task, deadline, and reward pool. Most bounties are free to enter; any rare bounty requiring an entry fee explicitly notes it upfront.

### On-Chain Security & Escrow
Prizes are locked in verifiable on-chain escrows on Solana before bounties open for submissions. You can audit the escrow program code directly at [github.com/makedotfun/prize-escrow](https://github.com/makedotfun/prize-escrow). Winners claim their payouts directly in USDC to their personal Solana wallets.

## Step-by-Step Tutorial

Follow these numbered steps to go from setting up your account to claiming your first bounty reward.

### 1. Create an Account
Get started by signing up at [https://make.fun/r/atshmk70](https://make.fun/r/atshmk70) using referral code `atshmk70`. You can authenticate securely with GitHub, Google, Apple, Discord, or a Solana wallet. Note that signing in with a Solana wallet is completely free and requires zero blockchain transactions.

### 2. Pick a Bounty
Explore active bounties on the platform dashboard. Review prompt specifications, deliverables, deadlines, and the reward breakdown. Select a challenge suited to your technical stack and agent capabilities.

### 3. Get the Kit
Install the official make.fun kit CLI (powered by Node 22) to initialize local workspaces, sync instructions, and manage submissions effortlessly. The platform supports a wide array of AI agents including Gemini CLI, Claude Code, Codex, Cursor, GitHub Copilot, opencode, Cline, and Aider.

### 4. Build Your Entry
Develop your solution through iterative prompts with your AI coding agent. A valid submission requires:
* A public GitHub repository frozen at a single commit.
* The complete transcripts of the AI coding sessions used to build the software, proving your agent did the work.

### 5. Submit Your Entry
Bundle your repository URL and session transcripts via the CLI or web interface and submit before the countdown timer expires.

### 6. Check, Fix, and Resubmit
Bounties progress through structured lifecycle stages: **Open** → **Submitted** → **Checked** → **Scored** → **Paid**. During the **Checked** stage, automated validation and peer reviews run. If minor gaps or warnings appear, refine your code, push the fix, and resubmit while the window is open.

### 7. Claim Your Reward
Once scoring concludes and your entry places in the winning ranks, the stage advances to **Paid**. Claim your USDC winnings instantly to your Solana wallet.

## Pro Tips for Competitors

* **Preserve Session Transcripts:** Always save and format your AI session transcripts cleanly. Missing or incomplete transcripts can disqualify otherwise functional code.
* **Read the Rubric:** Pay meticulous attention to specific output formats, test coverage requirements, and constraints specified in the bounty prompt.
* **Test Early, Submit Early:** Avoid last-minute network congestion or git tag issues by submitting an initial draft well before the deadline. You can update submissions during the Open/Checked stages.
